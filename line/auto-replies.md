# LINE公式「スペファミ」自動応答テンプレート

聞くことは3つに絞っています。

1. どんな団体か
2. 困っていること
3. 時期と予算（未定でよい）

お客さんは下の【回答用】を長押しでコピーし、書き足して送るだけで済みます。

設定場所：LINE Official Account Manager → 「スペファミ」

---

## 1. あいさつメッセージ（友だち追加の直後に届く）

設定場所：ホーム → チャットの設定 → あいさつメッセージ（または 設定 → 応答設定 → あいさつメッセージ「設定」）

```
{友だちの表示名}さん、友だち追加ありがとうございます。
未来ガジェット研究所（SpaceFamilyCompany）の吉岡です。

NPO・自治体・地域団体、そして個人・個人事業主の方の「これ、どうにかならない？」を、専用のアプリや仕組みで片付けています。

ご相談は、下の3つを送っていただくだけで大丈夫です。
わからない所は「未定」で構いません。

① どんな団体ですか（個人の方は「個人」とお仕事の内容で大丈夫です）
② いま困っていること（一言でOK）
③ 時期とご予算（未定でOK）

画面下のメニュー「LINEで相談する」を押すと、送りやすい形の質問が届きます。

相談と見積もりは無料です。
当日〜3日以内にお返事します。
```

---

## 2. キーワード応答

設定場所：ホーム → 自動応答メッセージ → 作成 → 「キーワード応答」をオン → キーワードを登録

LINE のキーワード応答は、送られた文がキーワードと**完全に一致したとき**だけ返信されます。

### 2-1. 相談の受付（リッチメニューの左ボタンと連動）

キーワード：`相談したいです`

```
ご相談ありがとうございます。
下の【回答用】を長押しでコピーして、書き足して送ってください。

――――――――
【回答用】
① 団体：
② 困っていること：
③ 時期・ご予算：
――――――――

＜書き方の例＞
① 会員30人ほどのNPO
② 毎年の事業報告に3週間かかっている
③ 来年3月まで・10万円くらい（未定でもOK）

写真やスクリーンショットも、そのまま送っていただけます。
内容を読んで、当日〜3日以内に吉岡からお返事します。
```

### 2-2. 料金

キーワード：`料金`、`見積もり`、`値段`

```
目安の金額はこちらです。

・報告書と事務の仕組み化　10万円〜
・オリジナルアプリ開発　30万円〜
・AI導入と職員向け勉強会　3万円〜
・ホームページと広報　5万円〜
・パソコン・ネット環境　1万円〜
・月額の相談窓口　月5,000円〜

予算に合わせて、できる範囲からご提案します。助成金・補助金の申請に添える見積書もお作りします。

詳しくはこちら
https://yousayrock.github.io/SpaceFamilyCompany/pricing.html

見積もりをご希望なら、メニューの「LINEで相談する」からどうぞ（無料です）。
```

### 2-3. 遠方・訪問

キーワード：`遠方`、`訪問`、`オンライン`

```
全国どこからでもご依頼いただけます。
相談から納品まで、ビデオ通話（Zoom・Google Meet）、電話、チャットで完結します。

所長は宮崎・長崎・大阪・千葉・新潟などを移動しながら開発しているので、旅の途中で近くを通るときは直接うかがうこともできます。
```

## 3. チャットの定型文（あなたが手動で返すとき用）

設定場所：チャット画面 → 入力欄の「定型文」アイコン → 新規作成

### 受付した直後

```
ご連絡ありがとうございます。吉岡です。
内容を拝見しました。いまのやり方をもう少し詳しく知りたいので、15〜30分ほどビデオ通話でお話しできますか？

ご都合のよい日時を2〜3つ教えてください。
（例：10/3 午後、10/5 10時〜）
```

### 情報が足りないとき

```
ありがとうございます。
あと1点だけ教えてください。

いま、その作業は「誰が・何を使って・どれくらいの時間」やっていますか？
（例：事務の1人が、Excelと紙で、毎月2日ほど）
```

### 見積もりを送るとき

```
お待たせしました。お見積もりをお送りします。

・内容：
・金額：
・期間の目安：

ご予算に合わない場合は、範囲を絞ったプランもお出しできますので、遠慮なくお知らせください。
```

### すぐ返せないとき

```
ご連絡ありがとうございます。
いま移動中のため、〇日中に改めてお返事します。少しお待ちください。
```

## 設定のチェックリスト

- [ ] 応答設定：チャット オン
- [ ] 応答設定：あいさつメッセージ オン → 上の 1 を貼る
- [ ] 応答設定：「応答方法」の選択肢があれば「手動チャット＋応答メッセージ」にする（キーワード応答とチャットを両方使うため）
- [ ] 自動応答メッセージ一覧：初期の「個別の問い合わせには対応していません」はオフ、または削除
- [ ] キーワード応答：2-1〜2-3 を作成してオン
- [ ] 定型文：3 を登録
- [ ] 自分のスマホで友だち追加し直し、あいさつと「LINEで相談する」の返信を確認
