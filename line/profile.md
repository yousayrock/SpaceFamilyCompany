## 操作メモ

- ステータスメッセージは、入力欄の右の **OK** を押して確定する。そのあと「公開」を押す。公開すると **1時間は変更できない**。
- パーツ（自由記述・基本情報）は、編集画面の「保存」を押してから、上部の「公開」を押す。
- 別の画面へ移動すると、保存していない編集内容は破棄される。
- 残りのタスクは GitHub の Issue で管理する。
